# Folder Arsip OpenSpec (Archive)

Folder ini digunakan untuk menyimpan proposal (`proposal.md`) dan spesifikasi fitur lama yang **sudah selesai diimplementasikan** dan diuji secara penuh.

## Aturan Pengarsipan:
1. Setelah semua tugas di `tasks.md` selesai dikerjakan, ubah nama file proposal menjadi format tanggal & nama fitur.
   - Contoh: `2026-09-13-eticket-qr-code.md`
2. Pindahkan file proposal tersebut ke folder `archive/` ini.
3. Kosongkan kembali `proposal.md` utama di root `openspec/` untuk proposal fitur berikutnya.
